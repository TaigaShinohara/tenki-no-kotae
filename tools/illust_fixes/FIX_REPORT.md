## 小2 レインコート＋マスク — ✅ 数値確定（コード変更1件）

**実測**（レインコート土台の焼き込み顔、mask帯域 fy 0.236〜0.304）：
- 肌幅は帯域上部で 0.44〜0.49 bw だが、口より下（fy 0.287〜）で 0.34→0.11 と急に細くなる（あごがフード内に引っ込む形状）
- 現行マスク布幅 = MASK_W 1.02 × cheek_w 0.464 = **0.473 bw**。下角が細くなった顔からはみ出しフード内壁に乗る。耳ひも含むマスク矩形の半幅は 0.316 bw で、フード開口の半幅 0.271 bw を超え、ひもがフード生地の上に描かれる
- 通常土台の cheek_w は 0.360〜0.365 で、レインコートの 0.464 だけが突出（開口幅で測った値を顔幅として使っているのが原因）

**提案する変更**（`PersonComposer`／ミラーでは RIGS の RAINCOAT の cheek_w）：
- **cheek_w（RAINCOAT）: 0.464 → 0.40**（布幅 0.473 → 0.408 bw）
- cheek_w の利用箇所はマスク布幅のみ（ミラー line 278 で確認）なので副作用なし

**実証合成**：`tools/illust_fixes/fix_small2/pair_mask_cheek.png`（左→右：現行 0.464／0.40／0.38）。0.40 でマスクが顔の中に収まり、ひもがフード縁に隠れる。0.38 はやや小さく、**0.40 を推奨**。
素材側の対応は不要（マスク素材自体は正常）。

## 小4 ランク0（BODY_B）の「手なし」問題 — ✅ 原因特定＋数値提案

**実測**：
- 素体のみの手まわり肌面積に対し、Tシャツ着用時の可視率は **50%**
- 原因は袖ではない：top_tshirt 素材の袖下端は素材高さの 0.45〜0.49（短い）。手を覆うのは**胴の両脇の垂れ**で、手（fy 0.530〜0.650）がちょうど裾の高さにあり、幅広に描かれた胴の陰に隠れる
- TOPCAL の高さ系（dy −0.012／h 0.80）は可視率 49〜50% で**効果なし**（裾と一緒に襟も動く）

**提案する変更**（検証済み）：
- **TOPCAL の top_tshirt の w: 0.70 → 0.64**（`PersonAnchors` の TSHIRT キャリブレーション第1要素）
  - 可視率 50% → **60%**、脇に腕のラインが出て手の存在が読める。シルエットの変化は小さい
  - w 0.60 だと 68% まで上がるが、シャツが明らかに細身になりデザインが変わるため非推奨
- 実証画像：`tools/illust_fixes/fix_small4/pair_topcal_width.png`（左 現行／中 w0.64／右 w0.60）、`pair_topcal.png`（高さ系候補が効かないことの証拠）
