方法： v0.1.25 の合成ロジックを正確に写した mirror_v0125 で現行の組み合わせを再合成し、拡大ズームクロップで目視。生成物は本フォルダの full/（98枚）・crops/（161枚）・pairs/（6枚）、一覧は manifest.txt。候補素材は sleeve_arms の配置則（preview_sleeve_arms.py の ARM）で合成して同様に確認。

## 中（直す価値あり）

### 中1. 頭部レイヤー下端に「服の断片」が残り、胸に水平な切り口線が出る
- 頭部レイヤー素材（layer_head_cap / layer_head_knitcap）の下部には、あごの下に汎用のシャツ襟と肩が描かれたまま残っている。画素確認でも、キャップ素材は最下行まで不透明幅 0.55〜0.68 と広く、ニット素材も首で細くなった後に最下部で 0.38 まで再び広がる（＝肩）。
- 合成すると、この断片が各服装の上に乗り、レイヤー下端の位置（体幹 fy≈0.40）に**真っ直ぐな水平線**が胸を横切る。実例：
- ランク3＋キャップ： ライトアウターの上にポロ風の襟断片。`crops/head_rank3_cap_head.png`
- ランク5＋キャップ／ランク6＋ニット： マフラーの上部を断片が横に切り取る。`crops/head_rank5_cap_head.png` / `crops/head_rank6_knit_head.png`
- レインコート＋キャップ/ニット： 光沢コートの胸に水平線＋無関係な襟。`crops/head_raincoat_cap_head.png` / `crops/head_raincoat_knit_head.png`
- サングラス＋キャップ（ランク4）でも同位置に線。`crops/sung_cap_rank4_face_neck.png`
- 出現範囲： キャップ（UV強の日）・ニット帽（雪の日）が出る全ランク＋レインコート。顔・髪そのものの馴染みは良好（下記「問題なし」参照）で、問題は下端だけ。
- 直し方： 両レイヤー素材の「あご下〜最下部」の服・肩部分だけをアルファで消す（キャンバスサイズと顔の位置は維持するので、アンカー再測定は不要のはず）。素材編集＋再検証のみで、手間は小。

### 中2. 日傘の腕が胴から離れて浮く（v0.1.26 候補素材）
- 付け根の拡大では、袖の塊が胴の肩と離れた位置に独立して浮き、腕の帯が傘の軸の向こう側にぶら下がって見える。肩の接続がない。`crops/sleeve_polo_parasol_root.png` / 握り自体は成立 `crops/sleeve_polo_parasol_grip.png`
- 既知の弱点「腕が胴の輪郭の外側に付く」の実像はこれ。組み込み前に直すのが安い。
- 直し方： 腕素材を「袖口が胴の肩に重なる」構図で再生成するのが本筋。配置の内寄せ・下げだけでも緩和はできる。再生成1枚＋再検証、手間は中。

### 中3. うちわの腕の上端が平らな切り口のまま頭の高さに浮く（v0.1.26 候補素材）
- 腕ストリップの上端が長方形の断片として髪の横に浮く。タオル併用でも干渉はしないが、切り口自体が目立つ。`crops/sleeve_polo_uchiwa_root.png` / `crops/sleeve_polo_uchiwa_towel_neck_arm.png`
- 直し方： 再生成（上端を丸く・短く、または髪の後ろに回す）か、腕全体を下げて切り口を肩の後ろへ隠す。手間は中。

### 参考： 現行 v0.1.25 の持ち物の「浮き」は腕素材で解消される範囲
- ランク0の日傘は、軸の下端が平らに切れて宙に終わり、手はシャツに隠れて握りが見えない。`crops/held_rank0_parasol_right_grip.png`
- ランク0のうちわ（自動の真夏セット）も、円盤＋短い柄だけで手が見えない。`crops/rank0_auto_hot_right_grip.png`
- レインコート現行は、軸が袖口の小さな手の切れ端に辛うじて届く程度。`crops/held_raincoat_open_right_grip.png`
- いずれも v0.1.26 の腕レイヤー／全身絵への置換で解消される設計であり、新規の指摘ではない（置換後に同じ見え方が残っていないかだけ要再確認）。

## 問題なしと判断した軸

- **頭部レイヤーの髪の色味・輪郭・顔位置**： 全土台（ランク0〜6＋レインコート）で色味とアウトラインは土台と馴染み、目・口は完全に残り、顔中心のズレもない（中1の下端断片を除く）。`crops/head_*_head.png` 全16件
- **マスク×マフラーの接近（再確認項目5）**： ランク4手動・ランク5・ランク6とも、マスク下端とマフラーの間に自然な隙間／乗りがあり、潰れ・はみ出しはない。ランク6はマスクがダウンの高い襟に自然に乗る。`crops/mask_muffler_rank4_face_neck.png` / `crops/mask_rank5_face_neck.png` / `crops/mask_rank6_face_neck.png`
- **サングラス×キャップレイヤー**： レンズは目の位置に一致し、つるは髪に隠れて自然。`crops/sung_cap_rank*_face_neck.png`
- **ニットコートの手（再確認項目2）**： 幅拡大後も両手とも「手」と読める。内側がコート前身頃に隠れるのは着衣として自然で、生存率66%の数値ほど悪く見えない。`crops/base_rank4_hands.png`
- **袖腕の傘3種（開・折りたたみ × ポロ/カーディガン/ニットコート）**： 握りと袖口の一致は良好。特にニットコート開の握りは指・フックまで自然。`crops/sleeve_knitcoat_open_grip.png` / `crops/sleeve_polo_folding_grip.png` / `crops/sleeve_knitcoat_folding_grip.png`。カーディガンの腕は太めで裸腕っぽく見えるが、色が服と近いため破綻ではない。
- **全身ポートレート5枚（再確認項目4・6）**： 画風・体格は土台と概ね一致（小のドリフトを除く）。レインコート傘のフード位置は元絵と一致し、握りも袖付きで自然。`crops/fig_raincoat_open_head.png` / `crops/fig_raincoat_open_grip.png` / `crops/fig_rank5_open_grip.png` / `crops/fig_rank6_folding_grip.png`
- **汗・震えなどの記号**： 汗は頬の高さで髪に乗るが記号として自然。震え線も服に被らない。`crops/towel_rank0_sweat_face_neck.png` / `crops/base_rank6_upper.png`
- **到達不能な土台 BODY_C**： 現行の自動ルールでは使われないため、合成上の問題は数えない（参考合成のみ実施）。

## プロセス上の注意（監査手法）

- v0.1.25 の監査スクリプト（audit25）と本監査の初回パスは、どちらも `spec_for(rank=3, base="RAINCOAT")` という指定をしていたが、mirror の仕様では rank 指定時に base が無視されるため、**レインコート＋頭部レイヤーの合成画は実際には BODY_A（タンクトップ姿）で描かれていた**。本監査では `audit_gen_raincoat_fix.py` で正しい RAINCOAT 土台に直して再生成・再確認済み（上記のレインコート所見はすべて修正後の画像に基づく）。今後の監査ではレインコート指定に rank を併記しないこと。
