# v0.1.25 — 頭部レイヤー（髪＋帽子は1枚絵）＋重ね着の再フィット

本人の指示2件への対応。

1. 「帽子などのかぶり物は髪型とセットで画像にしてほしい」— キャップ／ニット帽を、単品パーツを髪に重ねる方式から **頭部レイヤー**（髪＋帽子が1枚絵になった生成画像を土台の頭に被せる方式）へ切り替えた。
2. 「（重ね着が）まだ少しズレてる」（v0.1.24 実機の見た目テスト画面スクショ、ランク3／ランク4）— 開き前アウター2種の較正を実測し直し、肩まわりの幅不足を直した。

あわせて相談された腕レイヤー（傘などと腕のセット画像）は、本人が「腕は服装ごとに用意すべきでは」と再検討中のため **今回は入れていない**（後述）。

## 1. 頭部レイヤー

生成・キーイングの記録は `tools/layers_report.json`、配置則の検証プレビューは `tools/preview_layers.py`／`tools/previews_layers/`。

### 配置則（`PersonAnchors.headLayerRect`、純粋関数）

- スケールは均等：レイヤー内の顔幅（実測）がリグの顔幅に一致する倍率。
- 顔の中心 x と顔の上端をリグに一致させる。レイヤー内の顔ボックス（画像比率）：キャップ (0.349, 0.557)–(0.650, 0.975)、ニット帽 (0.306, 0.550)–(0.689, 1.000)。
- **レインコートだけ目線アンカー**：レインコートのリグ顔上端（0.081）はフード開口部の上端で額ではないため、顔上端基準では目が 0.121 に浮く（リグの目線 0.216）。レインコートではレイヤー内の目線（キャップ 0.654／ニット帽 0.650）をリグの eyeY に一致させる。このとき口は 0.264 に来てリグの口 0.260 とも合う。
- レイヤーは土台の髪を丸ごと覆う（被覆率はプレビューで 0.88〜1.00 を確認）。帽子が髪からズレる余地が構造的に無くなった。
- 描画順は従来の帽子と同じ位置（素体 → 首 → ミトン → **頭部レイヤー** → 顔（マスク／サングラス）→ 持ち物 → サイン）。旧 `drawHat` 経路と旧アンカー（CAP_*／KNITCAP_*／*_PAINT）は削除。

## 2. 重ね着（ランク2〜4）の再フィット

行ごとのシルエット幅を実測した（`tools/measure25.py`、BODY_A、v0.1.24 の較正値）。肩行（0.36〜0.40）での幅の余り（トップス幅 − 素体幅）：

| トップス | 肩行の余り（修正前） | 判定 |
|---|---|---|
| カーディガン | −0.009／0.000／+0.01 | ほぼ良好 → **不変** |
| ライトアウター | −0.037／−0.026／−0.018 | 肩が内側に寄っている |
| ニットコート | −0.046／−0.026／+0.02 | 特に細い（本人の見た目どおり） |

襟ピーク（0.324）と肩バンド上端は3種とも首の付け根（0.327）に合っていたので、修正は **sx（幅）のみ**。縦（sy／dy）は v0.1.24 の決定を維持した。

| トップス | topCal（sx, sy, dx, dy） | 肩行の余り（修正後） | 手の生存率 |
|---|---|---|---|
| カーディガン | (0.55, 0.45, 0, −0.003) 不変 | −0.001／+0.003／+0.008 | 70.4／69.9 → 同値 |
| ライトアウター | (0.60→**0.63**, 0.625, 0, 0.004→**0.000**) | −0.011／−0.005／+0.004 | 93.0／93.4 → **98.2／96.8** |
| ニットコート | (0.65→**0.67**, 0.60, 0, 0.011) | −0.035／−0.019／−0.004 | 71.6／72.0 → 66.3／66.3 |

- ライトアウターは dy も 0.004→0.000（襟ピーク 0.320、テスト帯 0.315–0.355 の内側）。
- ニットコートは Aライン形状の素材のため、肩幅の改善と裾行の広がり・手の生存率がトレードオフになる。生存率 −5.3pt を受け入れて sx +0.02 に留めた（+0.03 では裾行の余りが +0.07 を超え、生存率も 58 まで落ちる）。
- 単品トップス（ランク0／1）は v0.1.24 で確定済みのため不変。

## 5. 実機でしか分からない点

- 頭部レイヤーの髪と土台の髪の継ぎ目（色味・輪郭の馴染み）は実機の目が最終判定。
- ニットコートの手の生存率低下（66%）が実機で気になるかどうか。
- レインコート＋帽子の組み合わせは自動ルールでは出ない（雨の日は帽子より傘が優先される）ため、見た目テスト画面でのみ確認できる。
