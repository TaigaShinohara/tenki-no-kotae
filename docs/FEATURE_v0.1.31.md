## 2. 日傘：雨傘と完全同一を、手順と画像で証明し直した

- パソパソの再検品での不合格理由： 傘面が巨大化し、骨の収束点が画面右上の隅に寄って上端で切れ、頭の真上に傘が来ていない。「頭の後ろに巨大な扇が浮いている」ように見える。
- 実測で分かったこと： v0.1.30 の日傘素材は、アルファ（シルエット）が雨傘レイヤーと完全一致していた（差分 0 px）。つまり「形が変わった」のではなく、**雨傘レイヤーの承認済み構図そのもの**（収束点がレイヤー右上隅にあり、傘面が左へ大きく広がる）が、濃紺で背景に溶けていた雨傘では目立たず、明るい日傘では輪郭が際立って「巨大な扇」に見えた、というのが実態。
- 本版の対応： `tools/audit31/make_parasol_layer31.py` で雨傘から再生成し、証明を手順に組み込んだ。
  - アルファは一切書かない（assert で雨傘と完全一致を確認： 日傘だけのピクセル 0／雨傘だけのピクセル 0）。変わるのは傘面マスク内の色値だけ（192,974 px、v0.1.30 と同数）。再生成結果は v0.1.30 の出荷素材と同一バイト。
  - 証明画像 `tools/audit31/parasol_silhouette_overlay.png`： 雨傘のシルエット（赤）と日傘のシルエット（青）を重ねると全面が単一の紫になり、赤・青のはみ出しは一切ない。
  - 合成比較 `tools/audit31/pair31_parasol_vs_rain.png`（ランク1版も）： 雨傘の日と日傘の日で、傘の大きさ・位置・収束点・軸・腕・拳が一致して見えることを目視確認した。
- **正直な残件**： 検証項目「傘面全体がフレーム内に収まる」「てっぺんが頭の真上に来る」は、雨傘の承認済み構図では満たせない（雨傘の合成でも傘面は検証キャンバスの上端・右端に接し、収束点は頭の真上ではなく右上にある）。日傘だけを直すと「雨傘と完全同一」が崩れるため、本版では同一性を優先した。傘の構図そのものを変えるか（雨傘ごと作り直すか）はパソパソ／本人の判断待ちとして残す。
