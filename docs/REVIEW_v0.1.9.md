## 1. 背景＝「生きている空」（SkyView.kt、新規）

全画面共通の最背面に SkyView を置き、UI 列をその上に浮かせた（FrameLayout： SkyView → rootLayout）。駆動データは既存の取得済みデータのみ — 今日の天気コード・降水・日の出／日没と現在時刻。新規のデータ取得は追加していない。

| 空の要素 | 何を表すか | 駆動データ |
|---|---|---|
| 位相グラデーション（3点） | 時刻帯（夜明け／昼／夕方／夜） | 日の出・日没から dayness（0〜1）と warm（朝夕の橙み）を計算し、その日のティントの素地を位相色へ寄せる（式は ART_DIRECTION §3 v0.1.9 追記） |
| 環境グロー | その日の色の光（旧・主光の継承） | ティント（ライト α200／ダーク 白+22% α225）、結論の背後・半径 230dp |
| 太陽／月の弧 | いまの時刻の位置 | 上部右の弧を日の出〜日没／日没〜日の出で進行。可視度は dayness と雲量で連動 |
| 雲（7個プール） | 曇り具合（量と暗さ） | 天気コード → 雲量 0.06〜1.0、暗さ 0〜0.75。左→右へ数分で横断 |
| 雨の筋 | 雨の強さ（3段： 30／60／90本） | 天気コード＋降水量の補正 |
| 雪 | 雪の有無 | 天気コード 71〜77／85・86。60個、遅く横揺れ |
| 霧の帯 | 霧の有無 | 天気コード 45・48。横帯3本 |
| 星 | 晴れた夜（ダークのみ） | 月の可視度×（1−雲量）で出現、70個 |

- 天気コード対応（WMO、予備源 MET Norway も同じコード空間に変換済みのため両源で駆動）： 0=快晴／1=晴れ／2=薄曇り／3=曇り／45・48=霧／51〜57・61・80=雨1／63・66・67・81・95=雨2／65・82・96・99=雨3／71〜77・85・86=雪。補正： コードが雨でなくても降水 0.1mm 以上で雨1、雨の日に 2.0mm 以上で雨3。対象は「現在の時間帯」の時間別エントリ（無ければ最も近い時間）。
- データが無い状態（読み込み・エラー）： 天気要素なし、時刻だけから位相グラデーションを出す。
- 動きの規律： 約30fpsに制限、Activity が見えている間（onResume〜onPause）だけ描画。OS の「動きを減らす」設定（アニメーター無効／ANIMATOR_DURATION_SCALE=0）または省電力モードでは静止画（同じ状態の空）。点滅はなし — 雷は暗い雲＋強い雨で表し、稲妻は描かない。
- ダークモードの太陽・月は意図的に淡いグローに留めた（明るい円盤は結論の大きな文字の 3:1 ゲートを割るため。「ゲートが絵に勝つ」）。

- ラベル併用の判断： アイコンは「読む前に形で届く」先行表示として足し、置き換えはしていない。行動カードはピルのラベル（種類）＋アイコン（今日の状態）＋Rules の文章（答え）の3層。理由は minimal_information_design の原則どおり — 服の厚みや傘の状態は形が固定意味を持つが、「気圧の波線」など単独では固定しないものもあり、種類名と答えの文章は残すのが正解。漢字1字グリフのような文字の複写はしていない（v0.1.6 の二重表記の失敗の回避）。
- 詳細・設定では無理に足さず、見出しと統計の添えに留めた（グラフ自体が既に図形中心のため）。

## 3. コントラスト再走査

空の全定数（位相グラデーションの式、天体・雲・環境グローの色とα、ガラス面・ピル・ベタ）を、Kotlin の色計算（チャンネル毎 lerp＋切り捨て、sRGB 空間での source-over 合成、WCAG 輝度）を再現したスクリプトで走査した。範囲： 7帯×明暗×位相格子（dayness {0, .25, .5, .75, 1} × warm {0, .5, 1}）×全配置位置、最悪条件として「グリフがグロー中心に重なる」「雲が2枚重なる」を含む。

- **結果： 6,944 チェック全合格**
- 4.5:1 ゲートの最弱： **4.58**（ライト・寒い帯、ベタ上の onAccent 文字 — v0.1.5 から既知の律速で、空とは無関係のパーツ）
- 3:1 ゲート（大きな文字）の最弱： **3.09**（ダーク・あたたかい帯、dayness=1 かつ warm=1 という物理的に到達しない組合せでの太陽グロー）
- 雨・雪・星・霧は細線・小要素として対象外（霧の色・α は本文ゲートに影響しない淡さに固定）

## 4. 変更しなかったもの

- ロジック（Rules／WeatherApi／MetApi）、変換閾値、Rules の文言、色の役割（その日の色1色・7帯）、ガラス面・ピル・ベタの値、ホームの骨格と段階表示、詳細のグラフ、設定のセグメント／チップ。

## 5. 実機でしか分からない点（未確認として残す）

- 空のアニメーションの実際の見え方（雲の量感、雨の筋の目立ち具合、朝夕の色の移ろい）と「にぎやかすぎないか」の加減 — 数値ゲートでは測れない（v0.1.6 の教訓どおり）。実機スクショでの確認待ち。
- 描画の滑らかさ（約30fps の Canvas 描画が端末でどう見えるか）と電池影響（表示中のみ駆動・粒子数は上限固定だが、実測は未実施）。
- ダークモードで淡く抑えた太陽・月が「物足りなく」見えないか。
