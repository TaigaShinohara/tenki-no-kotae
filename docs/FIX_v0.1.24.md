# FIX v0.1.24 — 首タオルの巻き直し＋トップスの上寄せ＋マスクの顔合わせ（2026-11-22）

- きっかけ： 本人の実機・見た目テスト画面のスクショと指摘3件。①「タオルをつけたときタオルがズレてる」「首元の巻き部分と前に垂れる部分の収まりが不自然」——ランク6でタオルが首元から胸の中央を長く垂れる白い布（マフラーのよう／エプロンのよう）に見え、焼き込みマフラーとも二重になっていた。②「シャツが全部下に少しズレてる」——ランク1〜4の全トップスで縦位置がまだ少し低い。③「マスクつけたとき変」——最寒ランク（マスク＋マフラー）でマスクの位置・大きさが顔に対して不自然。
- 監査の方法： `tools/mirror_v0124.py`（v0.1.23 ミラーの複写に新値を反映）で合成し、`tools/audit24/` に before／after の拡大クロップ（タオルは全土台の首元、マスクは全土台の顔、トップスは肩・両手）を残した。実測は `tools/measure24.py`（素材の描画部・土台の顎／首／肩／頬幅の色マスク実測）。

## A. 首タオル： 原因と直し方

素材（prop_towel、689×983）の構造は、上部の巻き帯（素材の y 0.00〜約0.34、U字カーブの下端が中央で約0.34）＋左右に垂れるパネル（y 約0.36〜1.00、中央は胸が見える抜け）。旧配置は幅駆動（`TOWEL_W = 0.38`、v0.1.21 で 0.50→0.38）で上端 0.355。実測すると：

- 上端 0.355 は首の付け根（服の始まり ≈0.337）より**下**で、顎ライン ≈0.287 からも遠く、巻き帯が首でなく胸の上に浮いていた
- 自然アスペクトのため描画高は土台ごとにばらつき（0.167〜0.244）、パネル下端は 0.52〜0.60（BODY_C で 0.599）まで垂れてエプロンに見えた
- ランク6では帯が焼き込みマフラーの下端に引っかかり、タオルの白いパネルだけがマフラーの下から垂れる二重構造に見えた

直し方： マフラーと同じ**高さ駆動**へ変更（`PersonAnchors.TOWEL_H = 0.212`／`TOWEL_TOP = 0.298`、幅は素材アスペクト 1.43 から従属）。

- 上端 0.298 は顎ライン（≈0.287）とマフラーの上端（0.305）の間——帯が首に巻く位置
- 下端は全土台で 0.510（胸の上部）で統一。幅は土台により 0.33〜0.38
- マフラーとの重なり： レイヤー土台では首スロットが単一選択なので同時描画は起きない。ポートレートの焼き込みマフラーに対しては、タオルが首の位置からマフラーの上端を覆って前に垂れる形になり、「マフラーの下から白布が垂れる」破綻は解消した（after クロップで確認）。自動仕様は変更なし

## B. トップスの下ズレ： 原因と直し方

肩バンド（x 0.24–0.36／0.64–0.74）での実測： 体の肩ラインは BODY_A 0.327／BODY_B 0.330／BODY_C 0.312 に対し、v0.1.23 の描画トップスの肩は 0.336〜0.354 と**全トップスで 0.016〜0.027 下**にあった。襟は首の付け根に合っていたが肩が体より下で、タンクトップの肩ひもが服の肩の上にのぞく＝「服が下にズレて着られている」見え方の正体。

直し方： 全トップスの `topCal` の dy を一律 **−0.012**（ポロ 0.040→0.028／シャツ 0.026→0.014／カーディガン 0.009→−0.003／ライトアウター 0.016→0.004／ニットコート 0.023→0.011／ダウン 0.017→0.005）。scaleX／scaleY は不変。

- 肩ギャップは +0.004〜+0.015 に半減
- 襟は 0.318〜0.323 で首の付け根の帯（テスト帯 0.315–0.355）の内側を維持、裾も各服の着用丈の帯を維持
- 袖口が上がった分、手の生存率は全トップスで改善（シャツ 81→100%、カーディガン 39→70%、ライトアウター 67→93%、ニットコート 48→72%、ダウン 99→100%、ポロ 96→97%）

## C. マスク： 原因と直し方

素材（prop_mask、1024×662）の実測： 布（白の最大成分）の箱は素材の x 0.125–0.874／y 0.027–0.973 で、残りの幅は耳ひも。旧配置は素材矩形を「リグ顔幅 × 1.06」で置いていたため：

- 布幅は顔幅の約0.79倍しかなく、しかもリグ顔幅は頬幅と乖離する土台があり（BODY_A は顔箱が頬の実測 0.360 に対し 0.499）、土台ごとに布幅が 0.27〜0.43 とばらついた
- 布のアスペクト（h/w ≈0.82）が顔の鼻〜顎の形（≈0.46）より縦長で、布下端が全土台で顎（≈0.287）より 0.05〜0.08 下（0.337〜0.368）まで垂れた。ランク6ではマフラーの中にめり込み、大きな白い布が顔の下半分から首までを覆う「変」の正体

直し方： 帽子と同じ**描画部（布の箱）基準**の配置へ変更。リグに頬幅の実測 `cheekW` を追加（A 0.360／B 0.362／C 0.316／ランク5 0.365／ランク6 0.328／レインコート 0.464、いずれも y=0.27 の肌幅）し、`PersonAnchors.MASK_PAINT = (0.125, 0.027, 0.874, 0.973)`／`MASK_W = 1.02`（布幅／頬幅）／`MASK_H = 0.068`（布の高さ／体高）／`MASK_DROP = 0.020`（不変）。

- 布上端は全土台で 0.236（目のライン＋0.020＝鼻梁）、布下端は 0.304 で統一——顎（≈0.287）の少し下に巻いて止まり、マフラー（焼き込み上端 ≈0.33／レイヤー側 MUFFLER_TOP 0.305 の巻き帯の上端）には届かない
- 布幅は全土台で頬幅の 1.02 倍に揃い、耳ひもは顔の両脇で髪に消える
- マフラー併用時（ランク6＋マスク＋焼き込みマフラー）は、マスク下端とマフラーの間に首元が見える正しい重なりになった。レイヤー土台の手動併用（BODY_B＋マスク＋描画マフラー）でも布下端 0.304 がマフラーの巻き帯の上端 0.305 の直上で止まり、めり込みも浮きもないことを確認した（after クロップ）
