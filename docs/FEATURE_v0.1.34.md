# FEATURE v0.1.34 — 傘の形そのものを、1つの新しいデザインで作り直す

## 本人の指示（2026-11-23）

> 「どう？見直して。これ以上の改善が無理なら一度その部分だけ完全に作り直して」

## 見直しの結論（パソパソの所見）

v0.1.33 で構造（腕・握り・大きさ・全組み合わせの統一）は直った。しかし
傘面の「形」そのものが限界だった：

- v0.1.32 でプログラム描画した傘面は「深い円錐＋てっぺんに集まる骨線」で、
  特に白い日傘では傘ではなく尖った帽子／和傘の笠に見える
  （tools/audit34/cmp_rank0_parasol.png の左＝現行が分かりやすい）
- 傘面の幅も髪のボリュームに対して狭く、頭にちょこんと乗っている
  （腕レイヤーで傘面幅／髪幅＝0.87〜0.93、ランク5は0.69で大きく右寄り、
  カーディガンはてっぺんが顔中心から+47pxズレ — tools/audit34/measure34.py）
- 雨傘は濃紺で背景に溶けるため目立たないだけで、形の問題は雨傘・日傘共通

→ 継ぎはぎの改善は限界。傘の部分だけを、1つの新しいデザインで完全に
作り直す。人物・服・腕・袖・拳のピクセルは現行の承認済み素材を維持する。

## 新しい傘のデザイン（tools/audit34/design34.py）

全ランク・雨傘／日傘で完全統一。1つのパラメトリック設計関数
`draw_umbrella()` から全素材を描く（生成AI不使用）：

- 形：普通の傘を正面から見た、幅広で浅いドーム。幅は髪幅×1.1〜1.25
- ふち：頭の横では耳〜髪の中ほどの高さまで下がる緩い弧
- てっぺん：高い尖りは作らず、小さな突起（石突ノブ）だけ
- 骨線：8本。ドームの弧に沿う緩いベジェで、てっぺん周りの小さな
  キャップ楕円から広がる（1点収束＝笠に見える原因、をやめた）
- 軸：傘面の中心から拳まで一直線（握り位置・腕は現行のまま）
- 雨傘（濃紺）と日傘（白）は同一シルエットの色違い
  （アルファ完全一致を assert）

## 作り直しの内訳

### 腕レイヤー3種（ランク0〜4）— tools/audit34/build_arm34.py

旧傘面＋軸を消去→再キャンバス→新デザインを描画。保持ピクセル不変を
assert（腕・袖・拳は現行ピクセルそのまま）：

- ポロ（ランク0・1）：720→880幅。depth を 169→190 に深め、
  リムが髪の横でより下がって頭を覆う案を目視比較で採用
- カーディガン（ランク2・3）：746→940幅。てっぺんを約80px左へ動かし
  顔中心に一致させた（ズレ +47px → +0.2px）

日傘3種は雨傘版からの再着色で再生成（tools/audit34/

アルファ一致・袖布不変を assert）。

### 全身ポートレート3種（ランク5・6・レインコート）
— tools/audit34/make_variants34.py

全身絵に焼き込まれた傘だけを描き替える。手順：左パディングで
再キャンバス（ランク5・6は+70、レインコートは+30）→旧傘を消去→
穴を行ごとの水平補間で復元→新デザインをその絵自身のパレット＋
質感（モトリング）で描画。日傘は雨傘版の傘マスクだけを v0.1.33 の
輝度ランプで再着色（シルエット同一・人物ピクセル不変を assert）。
inner rect は x のみ再計算（y 不変＝poke・pad は従来どおり）。

消去・復元で踏んだ落とし穴（いずれも拡大目視で発見し対処）：

- 生成絵の傘アルファは斑点状に穴が開くため、輪郭走査が途中で止まり
  リム曲線が浅くなる → 許容ギャップ拡大＋上下エンベロープで対処
- 土台絵とバリアント絵は輪郭位置がピクセル一致しない（別生成）ため、
  髪の隙間は土台からのコピーでなく水平補間で埋めた
- 補間の片側フェードが長い消去区間では半透明の「板」になる
  （ランク5右上のタブ）→ フェードは縁から12px以内で消えるよう制限し、
  消去範囲も傘の実範囲に合わせて拡張
- レインコートの拳まわりは、消去ボックスが指の線を食べて縞になる
  → 拳（肌＋輪郭リング）を元絵からそのまま再貼り付けし、
  フックは拳の後ろから出す形に描き直した。旧フックの残像が出る帯は
  背景としてクリアしてから描画

- テスト：PersonFigureTest の v0.1.32 ピン留めを v0.1.34 の数値で
