# v0.1.20 — 見た目テストで服装を変えると連動要素が漏れる不具合の修正 記録

- 日付： 2026-11-22
- きっかけ： 本人が v0.1.19 の実機スクショ2枚を送り「キャラの見た目がおかしい」と指摘。見た目テスト画面で服装を手動で切り替えると、その日の自動 spec の服装連動要素が残っていた：
  1. 服装＝ランク0（半袖T＋短パン＋サンダル＋汗）を選んでも **マフラー** が巻かれたまま。
  2. 服装＝レインコートを選んでも **マフラー** と **震え線** が全身アセットの上に重なる。
  （当日は寒い日で、自動 spec はランク5〜6相当＝マフラー＋震えあり）

## 原因（確定）

`MainActivity.testSpec` の手動上書きが「服装スロット」だけを差し替え、服装連動要素の再導出が不完全だった：

- **首（neck）は再導出されていなかった** — 服装ブロックは garment／base／top／mittens／shiver／sweat を書き換えるのに neck だけ触らず、自動 spec の MUFFLER がそのまま残った（両スクショのマフラーの原因）。
- **震え（shiver）にレインコート抑制が無かった** — mittens／sweat には `!raincoat` が付いていたが `shiver = r >= 5` だけ素通りで、レインコート選択時は r＝当日の寒いランクのため発火した（スクショ2の震え線の原因）。
- 自動 spec（`PersonFigure.spec`）側は無事だった： レインコートは傘 NEED かつランク2〜4 のときにだけ発火し、その範囲では neck＝NONE・mittens＝false・shiver＝false・sweat＝false が構成上保証されていた。漏れはテスト画面の解決だけにあった。

同種の漏れの点検で、もう1件見つけた：

- **持ち物のうちわ** — うちわは自動ルール上ランク0連動（傘なし・UV 8未満の最暑ランク）。自動がランク0の日に服装だけ寒い側へ変えると、うちわが残った。逆に自動が寒い日に服装だけランク0へ変えても、うちわが出なかった。

## 修正

### 1. 服装連動要素の導出を一本化（PersonFigure.outfitLinked）

純粋関数 `PersonFigure.outfitLinked(rank, raincoat): OutfitLinked` を新設し、服装連動要素（首のマフラー有無／ミトン／震え／汗）の導出をここ1か所に集約した：

| 服装 | 首 | ミトン | 震え | 汗 |
|---|---|---|---|---|
| ランク0 | なし | – | – | ✓ |
| ランク1〜4 | なし | – | – | – |
| ランク5 | マフラー | – | ✓ | – |
| ランク6 | マフラー | ✓ | ✓ | – |
| レインコート（全ランク） | なし | – | – | – |

- `PersonFigure.spec` もこの導出を使うよう統一（首タオルは天気要素＝日中平均体感33℃以上、として導出結果の上に重ねる。レインコート時は重ねない）。自動 spec の振る舞いは従来と同一。
- `MainActivity.testSpec` は、服装を手動選択したら連動要素を `outfitLinked` で導出し直す。首はこの導出で置き、**首スロットを明示的にピンした場合はそちらが勝つ**（従来どおり後段の首ブロックが上書きする）。首を「自動」に戻せば服装連動に戻る。
- うちわも同じ考え方で追従させた： 持ち物が「自動」で、かつ自動の持ち物が うちわ／なし のときだけ、選んだ服装がランク0（レインコートでない）ならうちわ、それ以外はなしに再導出する。傘・日傘は当日の天気の答えなので自動のまま維持する。

### 2. 合成側の保証（PersonComposer）

`base == RAINCOAT` のとき、spec のフィールド値によらず **首（マフラー・首タオルとも）・ミトン・汗・震えを描かない** ことを PersonComposer 側でも保証した（`raincoatBase` ガード）。頭・顔・持ち物は従来どおり重なる。手組みの spec が来てもレインコートの上に連動要素は乗らない。

## 検証

- **Pythonミラー**（tools/preview_fix_v0120.py、本人のスクショ2ケースを修正前／後の解決で合成）：
  - ランク0＋首は自動： 修正前は半袖＋マフラー＋汗（スクショ1の再現）→ 修正後は **マフラーなし**、汗＋うちわ（`tools/previews2/r3_rank0_manual_before.png` / `r3_rank0_manual_after.png`）。
  - レインコート＋全部自動： 修正前はレインコート＋マフラー＋震え線（スクショ2の再現）→ 修正後は **レインコート単体**（`r3_raincoat_manual_before.png` / `r3_raincoat_manual_after.png`）。4枚とも目視確認済み。
- **単体テスト： 95件 全合格**（従来91件＋新規4件、コンパイル＋JUnit手動実行方式）。新規は PersonFigureTest の v0.1.20 節： `outfitLinked_followsTheOutfitAlone`（ランク別の連動表）、`outfitLinked_raincoatSuppressesEverything`（レインコートは全ランクで全抑制）、`spec_agreesWithOutfitLinked`（自動 spec と導出の一致＝テスト画面とホームの乖離防止）、`raincoatSpec_carriesNoLinkedElements`（ホーム側の自動 spec でもレインコート日に連動要素が乗らないこと）。
- ビルド： assembleDebug／assembleRelease とも成功。versionName 0.1.20／versionCode 21（aapt2 確認）。
- 署名： 証明書 SHA-256 = `fcf743c2388c8ae9f59f692b49755f479a0506208dbfb7a56ee2d36d80fef83f` で従来と同一（apksigner 確認、納品APKは検証済み debug APK とバイト同一）。
- 納品APK： `天気のこたえ_v0-1-20.apk`（8,770,669 バイト）。
