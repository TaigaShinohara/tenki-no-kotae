# FEATURE v0.1.36 — 夜は明日の天気を主表示に

本人の依頼（2026-11-26）：「夜見たときは明日の天気を見れるようにしてほしい」。

## 仕様

- 切替時刻は定数 `Rules.NIGHT_SWITCH_HOUR`（既定 **19時**）。この時刻以降、
  ホームの主表示は「明日」になる。
- 明日モードで明日データから生成するもの：
  - 結論1文（比較対象は「今日」。物差しは従来どおり 9〜18時の体感温度を
    同じ時間同士で比べる `matchedDaytimeAvgs`。共通時間が無ければ絶対評価
    「明日は〜」に落ちる）
  - 行動3つ（服装／傘／日焼け止め）
  - α枠（気圧）
  - 寒暖差の注記
  - 「今日の人」フィギュア
  - その日の色（トーン）
- 取り違え防止：ヘッダーに日付つきラベル「明日 11/27（金）」を
  アクセント色・太字で明示する。今日表示のヘッダーは従来どおり都市名のみ。
- 今夜は消さない：明日の主表示の脇に、今日の夕方以降の材料から
  `Rules.tonightLine` の1行（「今夜： …」）を残す。
- 今日へ戻す切替：自動で明日表示になっている時だけ、ヘッダー右に
  小さな「今日を見る」を出す。タップするとその表示セッションの間は
  今日表示を維持する（`homeManualToday`、永続化しない）。
- データが無い時：明日の時間別データが実在しない場合は明日表示にせず、
  今日表示のまま小行で理由を出す
  （「明日のデータが届いていないため、今日を表示しています」）。
  判定は `Rules.resolveHomeDay`（純粋関数・単体テストあり）。
- 詳細画面（数値で見る）：末尾に日付つき「明日の要点」カード
  （服装／傘／日焼け止め／気温／体感温度の日中平均）を追加。
  グラフと時間別表は従来どおり今日のもの。
- 変えないもの：空（SkyView）は「いま」の空のまま。ウィジェットの
  スナップショットも従来どおり今日の答えで保存する。

## データ取得

取得範囲の変更は不要だった：

- Open-Meteo：`past_days=1&forecast_days=3` で昨日・今日・明日（＋明後日）の
  時間別が既に届いている。
- MET Norway（予備源）：予報のみだが約2.5日分は時間別で、明日は丸ごと含まれる。
  （「今日」が現在時刻以降だけの部分日になる性質は従来どおり。）
