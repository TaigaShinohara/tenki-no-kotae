# v0.1.16 — 今日の人を生成画像アセットの合成へ（線画の廃止）

本人の指示（2026-11-20 夜）： 「人は画像にしよう。画像生成で用意して。組み合わせて使えるように工夫して。」

- 「今日の人」を線画（`PersonDrawer`、v0.1.14 新設・v0.1.15 描き直し）から、**生成画像アセットの合成表示**へ置き換えた。土台は服装ランク別の全身イラスト、小物（開いた傘／折りたたみ傘／帽子）は別アセットを固定アンカーで重ねる — 本人の「組み合わせて使えるように」に応える形。
- 描き分けの決定（どのランク・どの小物か）は従来どおり純粋関数 `PersonFigure.spec` で、**判定閾値は v0.1.14 から一切変えていない**（服装ランク 0..6、傘 NEED→開いた傘／FOLDING→折りたたみ、UV 6 以上で帽子）。震え・汗は画像に焼き込み済みのため、コード描画の震え線・汗マークは廃止した。
- 合成は `PersonComposer` の1実装をホーム（PersonView）とウィジェット（Bitmap 化）で共用する。旧 `PersonDrawer` は削除。

## 透過PNG化（tools/key_assets.py）

- **色距離キーイング**： 画像コーナーの中央値をキー色（実測 ≈ RGB(250, 3, 245)）とし、各ピクセルのキー色への RGB 距離でアルファを決めるランプ（距離 45 以下＝完全透過、130 以上＝完全不透明）。**連結成分方式は使わない** — 背景に接していない震え線・汗マークを消さないため（本人の指示どおり）。
- **デスピル**： 半透明〜不透明ピクセルについて、マゼンタ成分 `min(r, b) − g` が 15 を超える分を r・b から差し引く。キャラクターのパレット（紺・淡肌・白・グレー）にはマゼンタ成分が無いため、被写体側の色は壊れない。
- アルファのバウンディングボックスでトリミングし、長辺 1024px へ縮小。計測レポートは `tools/key_report.json`。
- **開いた傘だけ例外処理**： 生成傘は軸が短く、笠を頭上に保つスケールでは軸が手に届かない。そこでアセット段階で上部60%（笠＋軸の stub）にクロップし、合成時に軸のサンプル色でコード描画の線を手まで延長する（下記アンカー参照）。

## 合成とアンカー（PersonAnchors が正）

キャンバスは「高さ＝人の高さ、幅＝高さ/2」。人物は高さ一杯・下揃え・中央（生成素材が全ランク同一フレーミング＝中央・全身・足元揃えのため、トリミング後も baseline は一致する）。小物のアンカーは人の矩形に対する比率（0〜1）：

- 顔中心 x = **0.50**（全ランク共通）
- 右手（服装別、素材から実測： 肌／ミトンの重心）： ランク0 (0.74, 0.63)／1 (0.731, 0.633)／2 (0.733, 0.634)／3 (0.726, 0.614)／4 (0.767, 0.627)／5 (0.756, 0.629)／6 (0.90, 0.66)。ランク0（素腕）とランク6（ミトンで肌色検出不可）は推定値。
- 帽子： 幅 = 人の幅 × **0.60**、つば下端 = 人の高さ × **0.16**、頭中心に合わせる（雲髪の上にキャップが乗る）。
- 折りたたみ傘： 高さ = 人の高さ × **0.24**、中心 x = 手 x ＋ 人の幅 × 0.13、下端 = 手 y ＋ 人の高さ × 0.03（柄の下端＝アセットの下端を手の少し下に提げる）。
- 開いた傘： 幅 = 人の幅 × **1.12**、笠上端 = キャンバス高 × 0.005。軸の位置： アセット内の軸中心 x 分率 **0.507** が、人の幅 × **0.68** の位置に来るよう配置（軸が胴を斜めに切らず、体の右側を下りる）。軸の延長線はアセットより先に描き（stub が線の上端を覆って継ぎ目を隠す）、始点 = stub 下端、終点 = 右手アンカー、太さ = 傘幅 × 0.030、色 = **#001B44**（アセットの軸から実測 RGB(0, 27, 68)）。

合成の自己確認： Kotlin と同じ数式の Python ミラー（`tools/preview_compose.py`）で合成画像を作り目視した（`tools/previews/`）：

- `preview_rank6_umbrella.png`（ランク6＋開いた傘）： 笠が頭上を覆い、軸が体の右側を下りてミトンへ届く。良好。
- `preview_rank3_umbrella.png`（ランク3＋開いた傘）： 同上。良好。
- `preview_rank1_folding.png`（ランク1＋折りたたみ傘）： 右手の横に小さく提げた形。良好。
- `preview_rank0_hat.png`／`preview_rank2_hat.png`（帽子）： 雲髪の上にキャップ。良好。
- 棄却した案： 傘全体を回転させて持たせる案（幅 1.55 倍・傾き −13°）は笠が顔を覆って失敗。幅 1.30 倍は笠がキャンバス端で切れたため棄却し、1.12 に確定した。

## コードの変更

- `PersonFigure.kt`： `PersonDrawer` を削除。`PersonComposer`（アセットのデコード＋キャッシュ、合成描画）と `PersonAnchors`（アンカー定数）を新設。`PersonFigure.art(garment)`（服装→アセットの純粋対応）を追加。`PersonView` は (ctx, spec) の2引数になり、色引数（ink／accent）は廃止（画像はフルカラーのため）。`PersonFigure.spec`・列挙型・`PersonSpec` は無変更。
- `TenkiWidget.kt`： `personBitmap` を PersonComposer で 192×384 Bitmap に描く形へ置換（旧実装は幅 384 で描いて半分使っていなかった点も是正）。プレースホルダ（ランク3・素）も同じ経路。
- `MainActivity.kt`： PersonView の生成から色引数を外しただけ（レイアウト寸法は不変 — 人物 bitmap のアスペクト約 0.40〜0.44、笠幅でも View 幅 0.5H に収まる）。
- テスト： `PersonFigureTest` に2件追加（服装→アセット対応の全件確認、アンカーが人の矩形内に収まること）。既存8件は無変更で合格。

## 割り切った点・未確認事項（実機でしか分からない）

- **傘の軸は「アセット＋描画線」の継ぎ接ぎ**： 生成傘の軸が短いための措置。継ぎ目は stub の下に隠れる設計だが、実機の小さい表示で継ぎ目や色の段差が見えるかは未確認。
- **ランク0・ランク6の手アンカーは推定**： ランク0は素腕、ランク6はミトンで肌色ベースの自動検出ができなかった。折りたたみ傘（ランク0で提げる場面）と開いた傘の軸の終点が手から少しずれる可能性が残る。
- 人物の表示サイズ感・空（SkyView）との馴染み・ウィジェットでの見え方は実機未確認（従来どおり実機待ち行列）。
- APK サイズはアセット分だけ増えた（約3.6MB）。長辺 1024px に抑えてはいるが、表示は最大でも 148dp 高のため、将来さらに絞る余地はある。
