# FIX v0.1.22 — 持ち物の握り点アンカー化＋トップスの首元較正（2026-11-22）

- きっかけ： 本人の実機スクショ2件。①ランク0で「まだズレてるのがある」——うちわの円が体の右に浮き、柄は円の下の小さな突起として見えるだけで手と合っていなかった。②追加指摘「シャツもズレている。少し上にずれているようです」——ポロシャツの襟の先が顎にかかり、首が見えなかった。
- 監査の方法： 前版の Python ミラーを複写した `tools/mirror_v0122.py` で、持ち物（うちわ／折りたたみ傘／開いた傘／日傘）×素体（BODY_A／B／C＋ランク5／6ポートレート＋レインコート）の握り部と、全トップスの首元を **約3倍の拡大クロップ** で検証した（`tools/audit22/`、before／after 各38ファイル＋フルサイズ比較）。前版の監査はコンタクトシートの小さな表示で、今回のズレはその粒度では見落とす類だったため、検証粒度そのものを上げた。

## A. うちわのズレ： 原因と直し方

原因は2段重なっていた。

1. **配置方式そのもの**： うちわは「パーツの中心＋オフセット」で置かれていた。素材（800×1024）では柄は中央下部（x≈0.502、y 0.79–1.00）にあり、v0.1.21 でオフセットを 0.12→0.05 に詰めても、BODY_B の手（中心 x 0.732）に対して柄の中心がなお **+0.051（体幅比）右** にあった。手の幅は約0.039しかなく、柄（約0.045幅）と手が **まったく重ならない** ——円が体の右に浮き、柄だけが突起に見えたのはこのため。
2. **手が見えない素体**： ランク0のポロシャツは裾が体高0.692まであり、手（0.616–0.649）を完全に覆う。手が見えない以上、柄は「手のある位置」に正確に重ねないと持っている読みにならない。

なお、円の上部左から突き出て見えた細い棒状のものは、うちわの部品ではなく **Tシャツの袖付けの縫い目線** だった（円に下半分を隠され、上部だけが残って見えた）。握り位置を直した結果、円が縫い目を覆い、この読みも解消した。

直し方： **持ち物のアンカー方式を「握り点」方式に統一**した。持ち物ごとに「柄の持ち手位置」を素材分率で持ち（うちわ (0.502, 0.90)／折りたたみ傘 (0.52, 0.90)）、その点が素体リグの手の座標と一致するよう配置する（純粋関数 `PersonAnchors.gripOrigin`）。開いた傘と日傘は軸の x を手の x そのものにした。うちわは円が手の上に乗り、柄が手の位置でシャツに収まる形になった。

## C. トップスの縦ずれ点検結果

首・顎を実測した（全素体共通の傾向： 首は y 0.298–0.337 で細くなり、肩は約0.337から広がる）。襟の上端（中央帯±12%の最上端）の目標は A=0.335／B=0.330／C=0.330。現行（較正なし、または旧較正）の drawn 位置と補正：

補正は dy（下シフト）の一部を scaleY の圧縮で吸収し、裾の下降を抑えた（裾は全トップス 0.66–0.82 の着丈帯に収まる）。全トップスの首元拡大クロップで、襟が首の付け根に来て顎に掛からないことを確認した。検証を回帰テスト化（`topCollars_landAtTheNeckBase`： 全トップスの drawn 襟位置が 0.315–0.355 に入ること）。
