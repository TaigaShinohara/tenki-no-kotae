# FEATURE v0.1.33 — 日傘を雨傘の絵から作り直す

## 本人の指示（2026-11-23）

> 「日傘と腕生成がうまくいかない。傘と腕の生成はできているのでそれを参考にして作って」

雨傘＋腕の生成（v0.1.32 で作り直した腕レイヤー方式）はうまくいっている。
それを正本・参考にして、日傘＋腕を作り直すこと。

## 棚卸しと診断（現行 v0.1.32 の全出現組み合わせをレンダーして目視）

日傘（held=PARASOL）は自動ルールでは umbrellaLevel==NONE かつ UV>=8.0 で
全ランクに出現しうる。見た目テスト画面では服装と持ち物を独立に固定できるため、
全土台と組み合わせ可能。全8組み合わせをレンダーした診断
（tools/audit33/render33.py、diag_* 画像群）：

| 組み合わせ | v0.1.32 の経路 | 診断 |
|---|---|---|
| ランク0（BODY_B＋Tシャツ） | ポロ腕レイヤー | **健全**。日傘＝雨傘レイヤーの再着色で構造完全一致 |
| ランク1（BODY_A＋シャツ） | ポロ腕レイヤー | **健全**（同上） |
| ランク2（カーディガン） | 腕レイヤーなし→旧フォールバック | **崩壊** |
| ランク3（ライトアウター） | 腕レイヤーなし→旧フォールバック | **崩壊** |
| ランク4（ニットコート） | 腕レイヤーなし→旧フォールバック | **崩壊** |
| ランク5（全身ポートレート） | バリアントなし→素の絵＋フォールバック重ね | **崩壊** |
| ランク6（全身ポートレート） | バリアントなし→素の絵＋フォールバック重ね | **崩壊** |
| レインコート（テスト画面のみ） | バリアントなし→素の絵＋フォールバック重ね | **崩壊** |

フォールバックの崩壊の内訳（ランク2〜4・5・6・レインコート共通）：
- 傘面が v0.1.32 で作り直した傘面とは別デザインの旧小物（細く高い旧ドーム）が、
  頭部レイヤーの後に描かれるためキャップを覆う
- 軸は素の淡色バーが垂れた空の手の横で終わり、握りがない。両腕は空で垂れ下がる
- pad 0.34 の一律ルールで人物が縮む（腕レイヤーの poke は約0.17〜0.20）

不整合の指摘：ランク5・6・レインコートには「雨傘の腕レイヤー」が存在しない
（雨側は全身バリアント差し替え）。日傘だけがフォールバックに落ちていた。

## 作り直し

### 腕レイヤー（ランク2〜4）— tools/audit33/make_parasol_layers33.py

各組み合わせの日傘レイヤーを、対応する雨傘レイヤーそのものから再生成した。
腕・袖・拳・軸のピクセルは一切変えず、傘の紺だけを日傘色に置き換える
（v0.1.31/32 確立の再生成手順、audit32 の recolor() をそのまま使用）：

- `arm_cardigan_parasol.png`（746×1024）：袖布が淡色なので全体再着色
  （出荷済みポロ日傘と同一手法）。袖布の代表色ピクセルは無変更を assert。
- `arm_knitcoat_parasol.png`（655×1024）：袖布自体が紺系のため空間マスクで限定 —
  ①傘面域（列ごとの傘面下端＋回廊補間より上）②軸とフック（行ごとの左端の紺ラン＋
  拳帯＋最下行）③真のインク（lum<60 かつ最近傍アンカーがインク/軸）全域。
  袖内部は無変更を assert。
- 両方ともアルファ完全一致を assert。手法の再現性証明として、出荷済みポロ日傘を
  現行雨傘レイヤーから再生成しピクセル完全一致を確認した。
- アンカーは雨傘レイヤーのものを verbatim 流用（ARM_CARDIGAN_PARASOL /
  ARM_KNITCOAT_PARASOL）。

### 全身バリアント（ランク5・6・レインコート）— tools/audit33/make_parasol_variants33.py

雨側の生成方法（承認済みの全身絵）と同じ手順で、OPEN バリアント絵の中の
傘（傘面＋軸＋フック）だけを日傘色に再着色して新バリアントを作った。
人物ピクセルは不変、variantInner は OPEN と同一：

- `rank5_umbrella_parasol.png` / `rank6_umbrella_parasol.png` /
  `raincoat_umbrella_parasol.png`
- マスクは空間的に構築：傘面は列ごとのリム曲線（浮いている列は上端ブロブ下端、
  髪に接する列は実測の手設定点）、軸は実測した軸線の回廊（髪の前を通る箇所は
  インク輝度 lum<55 で限定し、髪スレート lum≈74 を守る）、レインコートのフックは
  拳右の小ボックス。
- 色は画材調の絵に合わせて輝度ランプ（日傘ファミリーの実測ストップを通る
  連続マッピング＋各ピクセルの灰色からの偏差30%保持）。近傍アンカー方式は
  斑点状に反転して汚れるため不採用（腕レイヤーはフラットな絵なので従来方式のまま）。
- アルファ完全一致・顔サンプル無変更を assert。
- ランク5の傘面と髪の接合部に、3倍拡大で見える程度の微小な残り（リムの小さな
  欠けと1px級のフリンジ）がある。合成スケールでは不可視と判断した範囲。

なお自動ルール上、ランク5・6 の日傘は UV>=8 と最寒ランクが同日に立つ必要があり
実質到達不能、レインコートの日傘は自動では出現しない（雨傘 NEED→OPEN が優先）。
いずれもテスト画面では到達可能だったため、そちらを直した格好。

## 残件（この版の範囲外）

- ランク5全身ポートレートの傘の構図そのもの（頭の右上に小さく乗る）は、
  承認済みの雨傘絵の構図をそのまま引き継いでいる。v0.1.32 から本人の判断待ちの
  件（全身絵の再生成が要る）であり、日傘も雨傘と同じ絵が正本という今回の
  指示の範囲では変更していない。
- フォールバック（旧小物＋コード軸）は DOWN トップスなどレイヤーのない
  ピン（テスト画面のみ）用に残置。
