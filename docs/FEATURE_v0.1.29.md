## 1. 日傘・うちわ：腕レイヤー方式から全身ポートレート方式へ

- 見立て： v0.1.28 のペア画像を再確認すると、日傘は傘面の中心が頭の中心から右に寄り、軸が髪の右端をかすめ、腕が軸の後ろに隠れて拳だけ見える形。うちわは腕レイヤーの袖〜上腕が胴の上に斜めのタスキのように乗り、円盤が手のラインから浮いて見える。どちらも「腕だけを別絵で貼る」部分合成の限界と判断し、これ以上レイヤー方式を詰めないことにした。
- 方針転換： ランク5・6の雨傘で実績のある **全身ポートレート差し替え方式**（既存の variant 仕組み）に切り替え。ランク0（BODY_B＋Tシャツ）とランク1（BODY_A＋シャツ）について「日傘を持つ全身絵」「うちわを持つ全身絵」を各1枚、計4枚を、各ランクの土台全身絵（ミラー合成の人物 rect 切り抜き）を下敷きにした編集生成で作成。1枚絵の中では腕も傘も最初から正しい位置にある。
  - 生成の合格条件： ①人物の身長・胴幅・顔の大きさが土台と数%以内、②日傘は傘面が頭の真上・軸は垂直・拳が軸を握る、③うちわは円盤が拳の上で上向き（アプリ既存のうちわ描写と表記を統一）。
  - 生成は日傘・うちわとも初回分が不合格（日傘：傘面の寄り／反対の手、うちわ：円盤が下向きに垂れる）で作り直し。日傘は出荷済みランク6雨傘の持ち方（頭の横で手を上げて握る）を明示して再生成、うちわは「円盤は拳の上で上向き、腰の横に立てる」を明示。ランク1うちわは3回目にランク0の合格絵をポーズ参照として渡して成功。
- 実測（`tools/audit29/measure29.py`、インクアンカー方式： 目の間隔で横スケール、目線〜ブーツで縦スケールを決める内側矩形。淡い夏トップスは肌色と近接して従来の肌成分ランドマークが破綻するため方式を変更）：
  - 内側矩形： ランク0日傘 (0.1951, 0.2091, 0.6492, 0.9999)／ランク0うちわ (−0.0005, 0.0005, 0.9108, 0.9992)／ランク1日傘 (0.1889, 0.1945, 0.6492, 0.9999)／ランク1うちわ (0.0017, −0.0005, 0.7745, 1.0001)。
  - シルエット一致（内側矩形で写像した生成絵 vs 土台、帯域別の幅比）： 髪 1.000〜1.004、腰 1.007〜1.014、脚 1.010〜1.018 — 全4枚とも数%以内。赤／シアンの重ね確認は `tools/audit29/overlay_keyed2_*.png`。
  - 傘面の中心： ランク0 +17.1% bw／ランク1 +17.4% bw（土台幅比、bbox 中心）。目標の2〜3%には届いていないが、同じ物差しで測ると **出荷済みのランク5・6雨傘ポートレートも +15.3%／+15.9%** であり、本人が承認してきた雨傘の幾何と同水準（傘面が頭全体を覆い、軸が顔の横を垂直に通る形）。数値目標より実績のある承認水準を優先して受理した。傘面の幅は 2.17〜2.20 bw（雨傘の 0.85〜0.89 bw より広い大判の日傘）。
  - 頭上パッド（poke）： ランク0日傘 0.2644／ランク1日傘 0.2415。日傘の日は人物が約2割小さく表示される（大きな日傘の幾何そのもの。雨傘の日は約1割）。
- 組み込み（`PersonFigure.kt`）：
  - `variantArt` の署名を (base, top, held) に拡張し、(BODY_B, TSHIRT) と (BODY_A, SHIRT) × PARASOL／UCHIWA に新 PersonArt（FIG_RANK0_PARASOL 等4点）を対応付け。
  - **腕レイヤーの抑止**： variant がある場合はコンポーザが腕レイヤーを描かない（従来は variant があってもポロ腕が重なってしまう構造だった）。保持物のフォールバック描画は従来どおり variant／腕の両方が無い場合のみ。
  - `padTopRatio` は variant 優先に再構成（variant がある日は variant の poke のみ＋頭部レイヤーの poke。腕の poke とフォールバック日傘の 0.34 は variant の下では発火しない）。
  - ポロ腕素材そのもの（arm_polo_parasol／arm_polo_uchiwa）は削除していない。コンポーザで variant に遮蔽されるだけ（素材削除ゼロの従来方針どおり）。
- 小物レイヤーの干渉確認（`tools/audit29/make_pairs29.py` のペア画像で目視）： 日傘の日（キャップ＋サングラス）は頭部レイヤーとサングラスがポートレートの上に正しく乗り、干渉なし。ただし握り手の一部は頭部レイヤーの髪の後ろに隠れる（ランク5・6の雨傘の日と同じ重なり方で、持ち方自体は読める）。うちわ＋首タオルも重なりなし。汗マークは従来どおり最前面に描かれる。
- 対象外（従来経路のまま・報告済み）：
  - 日傘は傘レベル NONE かつ UV ≥ 8 のとき全ランクで立つため、ランク2（カーディガン）・3（ライトアウター）・4（ニットコート）の日傘は従来経路のまま（カーディガン系は日傘の腕素材が無く握り点フォールバック、ニットコートも同様）。ランク5・6には日傘 variant が無くフォールバック描画のまま。
  - うちわは仕様上ランク0のみで立つ（傘レベル NONE かつ UV < 8 のとき）ため、ランク1うちわは実運用では発生しない手動組み合わせ。素材と配線は用意したが、これは記録用。
  - BODY_C 土台の手動組み合わせも不変。

## 2. マフラーの「小さな顔」修正

- 現象： ランク1＋マフラーで、あごの下・胸の中央に「薄い丸に点2つ」の小さな顔のようなものが見える（本人の実機スクショ指摘）。
- 正体の特定（確定）： 素材 `prop_muffler.png`（711×940）の巻き部分はドーナツ状の輪で、中央に実物の **透明な穴**（実測 bbox x 0.273〜0.713、y 0.241〜0.418、37,288 px）がある。配置（MUFFLER_TOP 0.305／MUFFLER_H 0.27）では穴が身体座標 y≈0.370〜0.413 に落ち、あご（≈0.288）・首元（≈0.337）より下の胸の上に来る。そこにシャツの前立てとボタン2〜3個が透けて「薄い楕円に点2つ」に見えていた。素材自体の結び玉の描画でも首の肌でもない。ランク4（ニットコート）＋マフラーでも、コートに焼き込まれたインナーシャツのボタンが透けて同一現象を確認。ランク5・6の焼き込みマフラーは穴のない帯＋垂れ2枚で正常。
- 直し方： 配置変更では直らない（穴を首の高さに合わせると巻き位置が壊れる）と判断し、素材側を修正。囲まれた透明穴だけをフラッドフィルで検出して布で埋めた。布色は素材の帯から実測した中央値 RGB (52, 74, 124)、帯の縦ストライプは「各列の真上の色を延長」する方式で穴内へ継続。キャンバス寸法・アンカー（MUFFLER_H／MUFFLER_TOP）は不変で、コード変更なし。
- 検証： `tools/audit29/pair_muffler_rank1_crop.png`／`pair_muffler_rank4_crop.png`（修正前後の拡大クロップ）で、顔が消えて通常の巻きマフラーに読めることを確認。全身ペアは `pair_muffler_rank1.png`／`pair_muffler_rank4.png`。
