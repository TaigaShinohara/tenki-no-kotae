# 天気のこたえ — 情報最小化の見直し記録 v0.1.8（大胆版）

- 実施： 2026-11-19。本人の指示「minimal-information-design-skillで全体を整備して。がんがんかえていいよ」。本人が v0.1.7 の実機スクショ3枚（ホーム／詳細／設定）を送ってきた上での指示。
- 位置づけ： v0.1.7 の見直しは「文字数を数えて少し削る」保守的なものだった。本版は本人の明示許可のもと、**表示の形そのもの**を変えた（数値の羅列 → 数字＋形、ラジオ → 操作UI、常時表示 → 折りたたみ）。v0.1.7 の判断のうち本版で更新したものは、その旨を明記する。
- 物差し： minimal_information_design スキル（核の8原則）。特に今回は 原則3（文字を図形・量・操作UIへ置き換える）、原則4（畳む）、原則5（Bは隠す。設計正本も詳細の数値を B と定義）、原則8（重要度順）。
- 不変のもの： ロジック（Rules／WeatherApi／MetApi／変換閾値）と Rules の出力文言。色の役割（その日の色1色）と Simple Glass の色付きガラス（v0.1.6 で本人が了承した形）。データの帰属表示（CC BY 4.0）は消していない。
- 主役（画面ごと、従来の決定を維持）： ホーム＝結論1文／詳細＝（主役なし）答えの裏付け／設定＝（主役なし）自分の感覚の申告／読み込み＝「取りにいっている」こと／エラー＝次にできること。

## 新しく入れた表現と狙い

1. **体感チャート（TempChartView）** — 狙い： 1日の寒暖と雨を「読む表」から「見る形」へ。線＝体感温度、バー＝雨、という対応は凡例1行（12字）で固定し、最高・最低は点＋値ラベルで数値も辿れる。現在時刻のリングで「今」が分かる。色は ink／補助色のみ（詳細は無彩色という §7 の方針を維持し、色相は面塗りのティントだけ）。読み上げ用に最高・最低を含む contentDescription を付けた。
2. **気圧スパークライン（PressureSparkView）** — 狙い： 気圧は「下がっていくのか」が本体で、絶対値の羅列ではない。折れ線＋最低点ドットで傾向だけを見せ、数値は現在値と1行に集約した。読み上げ用の contentDescription あり。
3. **折りたたみ「くわしい数値」** — 狙い： B ランクの完全な記録を、常時表示から外しつつ1タップで全て到達できる場所に置く。要点（グラフと数字）で足りる日は開かれないことが正しい。
4. **セグメントUI（segmentedControl）** — 狙い： 3択の排他選択を「選ぶ操作」そのものの形にする。タブバーで学習済みの型（ベタ＝選択中）を流用し、新しい語彙を増やしていない。
5. **地点チップ（cityChips）** — 狙い： 地点は「読むリスト」ではなく「押して切り替えるもの」。384dp の縦リストを 104dp にし、設定画面全体を1画面に収まる方向へ寄せた。

## 検証

- **単体テスト**： 既存26件・無変更で全合格（Gradle コンパイル＋JUnit 手動実行、実 org.json jar を android.jar スタブより前に置く従来方式）。
- **ビルド**： assembleRelease 成功（build.sh、Gradle 8.9・in-process）。途中2回、別プロセスの Gradle ビルドが共有キャッシュのロックを保持していて起動できず、その終了後に成功した（コード側の問題ではない）。
- **署名**： apksigner 検証済み、SHA-256 = FC:F7:43:C2:38:8C:8A:E9:F5:9F:69:2B:49:75:5F:47:9A:05:06:20:8D:BF:B7:A5:6E:E2:D3:6D:80:FE:F8:3F（従来と同一。納品コピーはビルド成果物と md5 一致を確認し、納品ファイル自体でも検証済み）。
- **バージョン**： aapt で versionName 0.1.8 / versionCode 9 を確認。
- **3秒テスト／無読テスト**： 未実施（初見の人間がいない）。未確認として残す。実機が得られたら最初に確かめる項目は「詳細を開いて、グラフだけで『いつ寒く・いつ降るか』が言えるか」。
- **ぼかし見テスト**： 仮判定・合格（コード上の照合）。詳細は要点カードの大きな体感数字が浮かび、残りは静か。設定は3つの面に集約された。
- **届きやすさ（親指）テスト**： 仮判定・合格。折りたたみ見出しは画面下部寄りの大きなタップ領域、セグメントとチップは 48dp 以上。危険な操作は存在しない。
- **折りたたみテスト**： 仮判定・合格。見出し「くわしい数値」だけで中身（全数値の一覧）が推測できる。
- **アクセシビリティ確認（静的）**： グラフ2種に contentDescription（最高・最低・最低気圧・最大下降を含む）を付けた。セグメントとチップはラベル文字そのものが名前になる。コントラストは色・面を変えていないため v0.1.6 の再走査結果が有効。ただし**時間別表のセル（13sp・数値のみ）が狭い画面で1行に収まるか**と、**グラフの最小値ラベルと時刻ラベルの重なり**はコード上の計算のみで、実機未確認。

## 実機でしか分からない点（正直に）

- グラフの見え方そのもの（線の太さ・バーの濃さ・面塗りの効き具合、最小値ラベルの位置）はコード上の設計値のみで、実機未確認。v0.1.5 の教訓どおり、数値とコードの照合は「読める」ことの確認であって「見た目が良い」ことの保証ではない。
- 時間別表の列幅は 360dp 級の画面幅を前提に配分した計算で、より狭い画面では「気圧hPa」見出しや 4 桁の気圧値が窮屈になる可能性がある。
- セグメントとチップの押下感・選択状態の分かりやすさは実機未確認。
- ダーク／ライト両モードでのグラフの見え方は未確認（色は既存トークンのみを使った）。
