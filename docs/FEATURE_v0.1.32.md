## 1. 何が問題だったか

- 従来の傘（生成素材の構図そのまま）は、傘面のてっぺん（骨の収束点）がレイヤー右上に寄り、傘面がフレームの上端・右端に接して切れて見えた。雨傘は濃紺で背景に溶けて目立たなかったが、明るい日傘では輪郭が際立ち「頭の後ろに巨大な扇が浮いている」ように見えた（v0.1.31 の検品結論）。

## 2. 作り直しの方法（`tools/audit32/draw_canopy32.py`、プログラム描画のみ）

- 生成AIの描き直しは使わない。各 OPEN 腕レイヤーについて：
  1. 旧傘面と旧軸だけを消す（傘面はコラム別の下端検出＋深コラム補間で、軸は拳の合流点まわりのコリドーで。**袖の付け根を守るため、腕にかかるコラムでは傘面の下端を浅く補間し、消去が袖・腕・拳に届かないことを assert で担保**）。
  2. キャンバスを透明余白で広げ、既存の絵の合成位置はアンカー再計算で完全不変に保つ。
  3. 軸を「新いてっぺん → 拳の合流点（実測： 傘を握る拳の中で旧軸が消える点）」へ一直線に引き直し、傘面をプログラム描画で新しく描く（16セグメント、骨線は素材実測の INK 色、面は実測 CLOTH 2色の交互、縁は波形）。
- 拳・腕・袖のピクセルは不変であることを assert で証明（消去マスク外は新旧完全一致。傘面の下端タックで袖の上端にかかる分だけが意図的な上書き）。
- 新アンカーは「グリップが従来どおり手の上に来る」ことから逆算して再解決（PersonAnchors.armAnchor／armPx と mirror の両方を更新）。padTopRatio は gripY／dhFrac 由来で不変。

## 4. ランク5・6／レインコートの全身ポートレート傘（確認のみ・無変更）

同じ物差しで計測した結果（`tools/audit32/{rank5,rank6,raincoat}_open_v32.png`）：

- **ランク6**： てっぺんは頭中心から +49 px（許容 ±134）で物差し内、傘面は顔を覆いフレーム内にも収まる。ただし大きな髪型の左右端までは傘面が届かない（髪の両端が傘の外に出る）。概ね適合として無変更。
- **レインコート**： 最終合成では傘面はフレーム内に収まりフードを覆う。てっぺんは頭中心のほぼ真上。ただし素材単体では傘面が左右端まで達して切れており、上端の余白も小さい（頭上の余白は pad 設計いっぱい）。無変更。
- **ランク5**： **物差し未達**。傘が頭の右上に小さく乗る構図で、傘面は頭（大きな髪型）の左半分を覆えていない。全身ポートレートの作り直しは生成素材の再生成が必要で影響が大きいため、本版では触らず**判断待ち**として残す。
