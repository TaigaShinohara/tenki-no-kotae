# FEATURE v0.1.37 — デザイン全面刷新（A案「そらグラデーション」）

本人の選定（2026-11-27）：デザイン案ボード12案（A〜L）から
**A「そらグラデーション」** を選択。参考モック：
`tools/design-board/media-generation-concept-a-sora-0-f56886b7-7a91-4f00-af7d-da9f7fc70d71.webp`

## A案の世界観と適用内容

- **背景は「空そのもの」**：空のグラデーションを「その日の色」由来から
  固定の空パレットへ差し替え（ライト＝淡い青 #8FB4E6 → #C2DCF5 →
  地平線の桃色 #FDEBCB／ダーク＝深い空紺 #132238 → #1B3350 → #243D59）。
  時刻の位相（dayness／warm、夜スレート・朝夕の橙み・昼の明るさ）の
  寄せ方は従来の式のまま、素地だけを差し替えた。太陽・雲・雨雪等の
  SkyView の要素と駆動データは不変。環境グローは ライト＝温かい陽光
  #FFEFD0 α170／ダーク＝淡い月光青 #9DB8D9 α110。
- **文字は空へ直置き（濃紺）**：本文 #1E2C5F（ダーク #EDF3FB）、
  補助 #2E3C72（ダーク #C9D9EC）。結論はその日の色をやめ本文色で
  直置き（ハローは存置）。「明日」ラベルと寒暖差の注記は
  そらアクセント（ライト＝濃紺 #1E2C5F／ダーク＝淡い空青 #A9C8F5）。
- **行動3項目はすりガラスカード**：面なしチップ（v0.1.13〜）をやめ、
  白の読み物ガラス（Simple Glass 正本値：ライト白 62%→54%／
  ダーク白 19%→13%、スペキュラ縁は従来どおり）のカードへ
  （角丸24dp、内側余白 横6dp・縦14dp、カード間8dp、アイコン28dpは
  そらアクセント）。色付きガラス（v0.1.6〜）は退役。
- **タブバーは浮いたピル型**：画面幅いっぱいの帯をやめ、左右16dp・
  下16dp の余白で浮く読み物ガラスの帯（角丸32dp、内側余白5dp）。
  各タブは線画アイコン（HOME／CHART／SLIDERS を Icons.kt に新設、
  20dp）＋ラベルの横組み。選択中はそらアクセントのベタピル
  （角丸28dp＝帯と同心）、アイコンと文字はベタ上の色へ切替。
  contentDescription とクリックはタブのコンテナが持つ（テスト互換）。
- **詳細・設定の統一**：カードは同じ白ガラス。セグメントの
  コンテナは固定の淡い空色（ライト #D9E5F3→#C7D8EE／ダーク
  #273D59→#1E314A）、選択中・地点チップ選択中・主ボタンは
  そらアクセントのベタ。体感チャートの面塗りは固定の空青
  #7FA8E0 の α（ライト115／ダーク95）。地点チップ未選択の面は
  空の上で消えないよう少しだけ濃くした。
- **ウィジェット**：面をスレート単色から夜空グラデーション
  （#2C4A73 → #456A94 → 暮れた地平線 #5F5258、縁 #54749E）へ。
  更新時刻の文字は #8FA3B0 → #C7D2DE に引き上げ。見出しの
  「その日の色」（スナップショットの accentDark）は存置——
  その日の色はアプリ内から退役し、ここが唯一の残り役になった
  （`toneFor` はそのためだけに残した）。
- あわせて設定フッターの版表記を実版へ追随（v0.1.23 のまま
  陳腐化していたものを v0.1.37 に）。

## 変えていないもの

- ホームの構造（B5：結論1文＋行動3つ＋α枠＋帰り1行＋明日1行、
  固定高・スクロールなし）。カード化に伴い高さ予算
  （`homeFixedHeightDp` のチップ会計 56＋行×20 → 83＋行×20）と
  タブバー高さの見積もり（84 → 92dp）だけを再積算した。
- 全ロジック・判定ルール・夜間明日モード（19時切替）・データ取得。
- キャラクター素材（パーツ式合成・較正済みアセット）には一切
  手を入れていない。フィギュア系ゴールデン9枚のうち3枚
  （parasol_rank5／rain_rank5_cap／rain_rank6_knitcap）は
  フルスイート文脈での再記録で髪色部に ±1 の丸め差分
  （最大Δ1・約850画素）のみが生じたため合わせて再記録した
  ——見た目の変更ではない。

## コントラスト再走査（WCAG、実装値そのまま）

明暗×位相（昼／朝夕／夜）×地（空の3ストップ／ガラスの実効色＝
カード下端の薄い側／ハロー込み）で全ペアを数値走査し、全ゲート合格。

| ペア | 最弱値 | ゲート |
|---|---|---|
| ライト：補助文字 × 空（夜・上端） | 4.58 | 4.5 |
| ライト：本文 × 空（夜・上端） | 5.82 | 4.5 |
| ライト：補助・本文 × ガラス（全位相） | 7.37 / 9.35 | 4.5 |
| ライト：結論 × ハロー込みの空 | 8.64 | 3.0（大きな文字） |
| ダーク：補助文字 × ガラス（昼の空の上） | 5.00 | 4.5 |
| ダーク：本文 × ガラス | 6.43 | 4.5 |
| ダーク：補助・本文 × 空 | 7.37 / 9.49 | 4.5 |
| ダーク：結論 × ハロー込みの空 | 14.25 | 3.0 |
| ベタ上の文字（ライト＝白 on 紺／ダーク＝紺 on 淡青） | 13.29 / 7.76 | 4.5 |
| ウィジェット：本文 #F5F1EA × 中ストップ | 4.98 | 4.5 |
| ウィジェット：更新時刻 #C7D2DE × 下ストップ | 4.83 | 4.5 |
| ウィジェット：地点 #B9C4CE × 上ストップ | 5.08 | 4.5 |

v0.1.6 の教訓（ダークで白の低アルファは灰色に濁る）は、地が
ティント由来の灰色がかった空だったことが前提。本パレットでは
地が固定の濃い空紺になり、ガラス上の最弱でも 5.00:1 を確保する。

## テスト

- 全137件合格（`tools/run-unit-tests.sh verify`、フルスイート）。
  内訳：ロジック系（Rules／Fetch／API／PartialDay／Fallback 等）、
  PersonFigure、画面遷移（Navigation）、画面ゴールデン5枚
  （home／home_night／detail／settings／person_test）、
  フィギュア系ゴールデン9枚。
- ゴールデン5枚は現行コードで再記録した。再記録は **フルスイート
  文脈** で行うこと：画面クラス単独で記録すると、共有サンドボックス
  時計のドリフト（数秒）の出方が変わり、新パレットはグラデーションの
  彩度が高いぶん ±1 の揺らぎ画素が許容（全面の5%）を超えて
  フルスイート検証で落ちる（今回踏んだ。比較の許容値は不変）。
- 検証時の注意：この VM では他プロジェクトの Gradle が共有
  Gradle ホームのジャーナルロックを握ることがあり、開始が
  60秒タイムアウトで落ちることがある（ロック競合時は時間を
  置いて再実行する。ビルド自体の失敗ではない）。

## 残った課題（実機待ち行列）

- A案の空気感そのもの（桃色の地平線の柔らかさ、ガラスの浮き方、
  ダークモードでの見え方）は数値ゲートでは測れない
  （ART_DIRECTION の v0.1.6 教訓）。実機スクショでの見え方確認は
  本人のタイミング待ち。
- ウィジェットのプレビュー画像（drawable-nodpi/widget_preview.png）
  は旧スレート色調の模式図のまま（ランチャーの追加画面用。実表示は
  新デザインで描かれる）。気になる場合は次版で空色調に差し替える。
