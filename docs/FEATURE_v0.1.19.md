# v0.1.19 — 今日の人をレイヤー合成へ（パーツ組み合わせ＋見た目テスト画面）

本人の指示（2026-11-22）： 「中央のキャラのクオリティを上げます。見た目はこれで完成でいいので、天気に応じたパターンをもっと作って。パーツごとに作ることで組み合わせれるように工夫して。またテスト用に見た目を切り替えれる画面も作っておいて。」

- 「今日の人」を、ランク別全身イラスト1枚（v0.1.16）から **パーツのレイヤー合成** へ作り替えた。キャラクターの見た目（雲のような濃紺のもこもこ髪・淡い水色の肌・中性的な顔立ち、本人が v0.1.16 で確定）はそのままに、素体3種＋トップス6種＋小物11種を組み合わせて着せ替える。
- 天気に応じた新パーツと自動ルールを追加した： ニット帽（雪の日）、サングラスと日傘（UV 8 以上）、うちわ（いちばん暑いランク）、首タオル（猛暑）、マスク（寒くて乾いた日）、レインコート（傘がいる日の中間ランク）。
- 設定に **見た目テスト画面** を追加した。全スロットを手で切り替えて、その場で同じ合成エンジンのプレビューを見られる（テスト用の切り替えは保存されず、ホームには影響しない）。
- 描き分けの決定は従来どおり純粋関数 `PersonFigure.spec`。服装ランク／傘／UV帽子の閾値（v0.1.14）は不変で、入力に雪・日中平均体感・日中平均湿度が増えた。

## 採用方式（ランクごと）

方式は Python ミラー（`tools/preview_parts.py`、Kotlin と同じ数式）で全ランクの合成プレビューを作り、目視で決めた。

| ランク | 方式 | 土台 | トップス |
|---|---|---|---|
| 0（半袖） | レイヤー合成 | BODY_B | TSHIRT |
| 1（長袖シャツ） | レイヤー合成 | BODY_A | SHIRT |
| 2（カーディガン） | レイヤー合成 | BODY_A | CARDIGAN |
| 3（ライトアウター） | レイヤー合成 | BODY_A | LIGHT_OUTER |
| 4（ニット＋コート） | レイヤー合成 | BODY_A | KNIT_COAT |
| 5（冬コート＋マフラー） | **ハイブリッド** | RANK5_PORTRAIT（v0.1.16 の全身画像） | なし |
| 6（ダウン） | レイヤー合成 | BODY_C | DOWN |
| レインコート日 | 全身差し替え | RAINCOAT（outfit_raincoat） | なし |

- ランク5をハイブリッドにした理由： 冬コートのトップス素材（top_wintercoat）は商品写真の比率で、どの素体にも合わなかった（幅で合わせると頭から足まで届き、高さで合わせると素体の腕がはみ出す）。そのためランク5だけ従来の全身画像を土台に残し、新パーツ（ニット帽・マスク・サングラス・傘など）だけを上から重ねる。マフラーと震え線は画像に焼き込み済みなので二重には描かない（`PersonComposer` の hybrid 分岐）。
- レインコートは専用の全身アセット（フード付き合羽＋長靴）で服装ごと差し替える。傘がいる（UmbrellaLevel.NEED）かつランク 2〜4 の日だけ。

## 合成の仕組み（PersonCanvas / PersonRigs / PersonAnchors）

- 素体・トップス・レインコートは **1枚の共通キャンバス（1120×2240）** の中で生成し、`tools/key_parts.py` で透過化＋アルファ bbox で切り出した。各パーツのキャンバス内 bbox が `PersonCanvas.box` の正本で、合成時は素体の bbox 高さが「人の高さ」になるようキャンバス全体を拡縮し、全パーツを元の位置に戻す。
- 小物（帽子・マスク・サングラス・マフラー・タオル・手袋・傘・日傘・うちわ・折りたたみ傘）は素体ごとに実測した **リグ**（顔の箱と両手の位置、`PersonRigs`）から `PersonAnchors` の比率で置く。リグは素体3種・ランク5全身・レインコートの5種分あり、ハイブリッド土台でも同じ小物の置き方が効く。
- 描画順： 土台（素体→トップス）→ 首（マフラー／タオル）→ 手袋 → 頭（キャップ／ニット帽）→ 顔（マスク／サングラス）→ 持ち物 → コード描画の記号（汗・震え）。全身画像をやめたため、汗と震えは線画時代と同じくコード描画に戻した。
- ホームの高さ決め（v0.1.18 の `heightDp`）は、日傘・ニット帽の頭上パッド（`padTopRatio`： 日傘 0.34／ニット帽 0.04）をブロック全体で予算化する形に拡張した。

### 較正定数（PersonCanvas.topCal）

トップスは商品写真の比率（着丈が長い）で生成されたため、2着だけ着用時の長さへ圧縮する。形式は (scaleX, scaleY, dx, dy)、dx/dy は素体比。

| トップス | scaleX | scaleY | dx | dy | 備考 |
|---|---|---|---|---|---|
| CARDIGAN | 0.82 | 0.55 | 0 | 0.05 | 横も絞って着用感を出す |
| KNIT_COAT | 1.00 | 0.83 | 0 | 0.04 | 縦圧縮のみ |
| その他 | 1.00 | 1.00 | 0 | 0 | 較正なし |

小物のアンカーは `PersonAnchors` が正本： キャップ（幅＝人の 0.48、帯下端 0.26）／ニット帽（0.54／0.245）／マスク（幅＝顔幅 ×1.06、上端＝顔の上端＋顔高 ×0.46）／サングラス（幅＝顔幅 ×1.12、中心＝目の線 0.57）／マフラー（高さ＝人高 ×0.32、上端 0.29）／タオル（幅 0.50、上端 0.355）／手袋（高さ 0.115、手は 0.42 の位置）／日傘（幅 1.15、上端 −0.30＝頭の上）／うちわ（高さ 0.21、右手の横）／折りたたみ傘（新素材、高さ 0.30）。開いた傘は v0.1.16 の素材と軸の延長描画を継続（幅 1.12、軸位置 0.68、軸色 #001B44）。
- 旧素材の item_hat（キャップ）と item_umbrella_folding は新素材（prop_cap／prop_folding）に役目を譲り、合成では使わない（ファイルは残置）。

## 自動ルール（PersonFigure.spec、閾値は PersonFigure の定数）

| パーツ | 条件 | 備考 |
|---|---|---|
| ニット帽 | その日のいずれかの時間に雪の天気コード（71/73/75/77/85/86） | キャップより優先 |
| キャップ | UV 最大 6 以上（v0.1.14 から不変） | |
| サングラス | UV 最大 8 以上 | |
| 日傘 | UV 最大 8 以上 かつ 雨傘なし | 持ち物の優先順位は 雨傘（開いた傘＞折りたたみ）＞ 日傘 ＞ うちわ |
| うちわ | ランク0 かつ 傘・日傘なし | |
| 首タオル | ランク0 かつ 日中（9〜18時）平均体感 33℃ 以上 | |
| マフラー | ランク5以上（v0.1.14 から不変） | |
| 手袋（ミトン） | ランク6 | |
| マスク | ランク4以上 かつ 日中平均湿度 40% 未満 | |
| レインコート | 傘がいる かつ ランク 2〜4 | 服装ごと差し替え |
| 汗 | ランク0／震え： ランク5以上 | コード描画に戻した |

- 入力の追加： WeatherApi が `relative_humidity_2m` を取得し、`Rules.daytimeHumidityAvg`（9〜18時の平均、該当時間が無ければ null）を新設。MET Norway 予備源も湿度を持つ。**入力が無いルールは推測で発火しない**（null なら出さない）。
- マスク素材は候補2種（prop_mask_a／b）のうち **b** を採用した（`drawable-nodpi/prop_mask.png` は b と同寸 1024×662）。

## 見た目テスト画面（設定 → 見た目テスト）

- 入口は設定画面の「見た目テスト」セクション（主ボタン「見た目テストを開く」）。
- 上半分は空（時刻を 現在／昼／夕方／夜 で切替可能）＋ホームと同じ PersonComposer のプレビュー、下にスロット別のセグメント操作： 服装（自動・0〜6・雨）／頭（自動・なし・帽子・ニット帽）／顔（マスク、サングラスは別セグメント）／首（自動・なし・マフラー・タオル）／持ち物（自動・なし・傘・折りたたみ・日傘・うちわ）。各スロットの先頭は「自動」＝その日のデータの答え。
- 切り替えは保存されない使い捨ての状態で、ホームは一切読まない。戻る導線は「設定にもどる」ボタン。

## 実機でしか分からない点（未確認）

- レイヤー合成の継ぎ目・較正の効き具合の最終判定は実機の目（プレビューは Python ミラーで、端末の Bitmap 拡縮とはフィルタが違う）。
- 日傘の日： padTop で人を小さくする分、結論やチップとの距離感がどう見えるか。ニット帽が髪の上に「乗っている」ように見えるか。
- ランク6で顔がほぼ隠れる点が「完全防備」として伝わるか、ただ顔が見えなくて寂しくないか。
- 見た目テスト画面のプレビュー高さ（330dp 枠）での各スロットの収まり、特に日傘＋ニット帽など頭上が高い組み合わせ。
- ウィジェット側の合成（同じ PersonComposer を Bitmap 化）でも新パーツが同じに見えるか。
