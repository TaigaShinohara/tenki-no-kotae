# FEATURE v0.1.26 — 「今日の人」に袖つき腕と傘つき全身絵を組み込む

- 日付： 2026-11-22
- 種別： 機能（素材の組み込み）
- 対象： `PersonFigure.kt`（PersonArt／PersonAnchors／PersonComposer／padTopRatio）、新規 drawable 14点、単体テスト
- 前提： v0.1.25（頭部レイヤー）。素材は `tools/sleeve_arms/` の量産バッチ（腕レイヤー8点＋全身ポートレート5点＋ランク6試作 proto2）が正本で、本バージョンはそのアプリ組み込み。

## 本人の決定（背景）

- 傘の持ち方について本人が「腕は服装ごとに用意すべき」と提案 → パソパソの「袖グループ方式」（服装を袖の形で3グループにまとめ、グループごとに腕＋持ち物の1枚絵を用意する）を採用。
- 試作（ランク6＋開いた傘）が2版目で合格条件を満たし、本人が「この方式で量産する」を選択（2026-11-22）。量産13枚＋試作1枚＝14枚が検証済みで納品された。

## 方式

### レイヤー合成側（ランク0〜4）＝腕レイヤー

- 袖グループ： ランク0・1＝ポロ半袖、ランク2・3＝カーディガン、ランク4＝ニットコート。
- 腕レイヤー（袖＋腕＋持ち物が1枚絵）を「素体→トップス」の直後に描く。そのランクで表示される持ち物の単品描画は腕レイヤーに置き換える（単品の傘・腕が重なって二重腕になるのを防ぐ）。
- 配置アンカーは量産バッチの検証用プレビュー（`tools/sleeve_arms/preview_sleeve_arms.py` の ARM 記録）が正本： 握りの点（素材内の手の位置）を土台リグの手の座標へ一致させ、開いた傘は軸の x も手に合わせる。大きさは土台の幅・高さに対する比率、折りたたみ傘とうちわは握りを中心に回転（プレビュー＝PIL の回転角で記録し、コンポーザ側で符号を反転）。
- 腕レイヤーが無い組み合わせ（日傘・うちわはポログループのみ用意。自動ルールでは出ない手動テスト画面の組み合わせ等）は、従来の握り点方式（v0.1.22）にフォールバックする。

### 全身絵側（ランク5・6・レインコート）＝傘つき全身絵への差し替え

- 傘「いる」→開いた傘版、「折りたたみでOK」→折りたたみ版の全身絵に土台ごと差し替える（単品傘の重ねはしない）。傘「いらない」の日は従来の全身絵のまま。
- 差し替え絵は人物の写り方が土台と少し違う（開いた傘版は人物が 0.83〜0.90 倍・下方寄り）ため、実測した「内側矩形」（差し替え絵の中で土台の人物が写っている範囲）を土台の人物 rect に一致させて描く。これで頭部レイヤー・マスク・サングラス等のリグ依存プロップの位置は土台のときと完全不変に保たれる（内側矩形は土台のリグ顔箱・目線を検出器が再現できることで検証済み）。

### 頭上パッド（padTopRatio）

- 日傘 0.34 はフォールバック時（単品日傘を頭上に掲げる旧描画）のみの値になった。腕方式・差し替え方式では、実際に頭上へ張り出す量の実測（poke）から決める： 開いた傘の腕＝ランク0 0.18／ランク1・カーディガン 0.17／ニットコート 0.18、差し替え絵＝ランク5 0.13／ランク6 0.12／レインコート 0.21、折りたたみ版は 0。頭部レイヤーの張り出しとは最大値を取る。

## 旧素材の扱い

- 削除した素材は **ゼロ**。旧単品素材（傘3種・日傘・うちわ・汎用腕3種）はすべてフォールバック経路（腕の無いグループでの日傘・うちわ、ランク5・6・レインコートのフォールバック日傘、ダウン＝ランク6レイヤー合成側の手動表示など）で現役のため残置した。

## 既知の弱点（素材由来・量産バッチの記録どおり）

- 日傘の腕は胴の輪郭の少し外側に付く。うちわの腕の上端は平らな切り口。
- 開いた傘の腕レイヤーは傘面が大きく、人物の頭上いっぱいに広がる（バッチの検証プレビューと同じ見え方）。アプリの表示枠では頭上パッドで収まる。
