# v0.1.15 — 実機フィードバックを受けた見た目の手直し 記録

- 日付： 2026-11-20
- きっかけ： 本人が v0.1.14 の実機スクショ（大阪・夜、服装ランク6＝ダウンの日）を送り、手直しを承認した。パソパソ側の読み取りで課題は3点に整理された。

## 課題 → 直し方

### 1. 「今日の人」が細く小さく、棒人間に見える

- 課題： ダウンの日なのに上着の膨らみがなく、マフラーは細い線1本に見える。服装ランクの着替えが絵で判別しにくい。原因は描画側にあった： v0.1.14 の PersonDrawer は全ランクで胴の半幅がほぼ同じ（約5〜6ユニット）で、ランク差は内側の線（キルト・ラペル等）だけで付けていた。線幅も 1.9 ユニットと細く、104/124dp の表示では線が潰れて棒状になった。
- 直し方（PersonFigure.kt の PersonDrawer を全面改修。`PersonFigure.spec` の意味・戻り値は無変更）：
  - **シルエットで段差を付ける**： 全ランクを「首→肩→袖の筒→脇→胴の側面→裾」の1本の輪郭で描き直し、高さごとの幅そのものをランクで変えた。胴半幅： 半袖 約6（＋短い袖・素足の脚・短パン）／シャツ 約6.7／カーディガン 約7（＋開いた前の V と前立て）／ニット＋アウター 約8（＋中のニットの首と前縁）／コート 胴 約7→裾 約10.5 に広がる A ライン（＋ラペル・ボタン）／ダウンは胴と袖の側面を弓なりに膨らませ、袖込みの最大半幅 約11.5。脚も立ち幅を広げ、輪郭の太さで「筒」に見えるようにした。
  - **線を太く**： 輪郭 1.9 → **2.7 ユニット**、中位の詳細（キルト線・マフラーの巻き）2.3、細部 1.9 の3段に再配分。頭も半径 6.2 → 6.6 に拡大。
  - **マフラーを「巻いた塊」に**： 細線1本（首の下の弧＋垂れ2本）から、首元に2段の巻き弧＋両端を閉じた帯＋幅のある垂れ（2本線＋房）に変更。細線には見えない太さになった。
  - **手袋を手の形に**： 袖口の小円（半径 2.7）から、袖の筒の先に付く半径 3.3 のミトン型の丸に拡大。通常ランクの手も半径 2.1 に拡大し、袖口と接続させた。
  - **ダウンの追加要素**： キルト線は胴の全幅に3本（太さ 2.3）＋袖にもキルトの刻み、高襟は2重の弧で厚みを付けた。
  - 震え線・汗マークは維持（震え線は太くなったシルエットに合わせて外側へ移動）。アニメーションなしの静止記号のまま。
- ウィジェットの人（PersonDrawer 共用・Bitmap 化）にも同じ改修がそのまま効く。ウィジェット側のレイアウトは無変更。

### 2. チップアイコンが実際のサイズで読めない

- 傘「いらない」（Icons.kt の UMBRELLA_NONE）： 波形（スカラップ）の笠＋全体を貫く斜線＋穂先の小線が、30dp のチップ表示で花／星型に見えた。→ 笠を **広く滑らかなドーム**（波形は浅い2つだけ、穂先は廃止）に描き直し、柄とフックを長く残した上で斜線を引く「禁止ピクトグラム」形にした。笠の形が先に読め、その上に斜線が乗る。
- 服装・ダウン（DOWN）： マフラーの垂れ尾2本がキルト線と重なって鞄の取っ手＋ポケットに見えた。→ アイコンのダウンからは垂れ尾を外し（巻き帯の弧だけ残す）、キルト線は3本→2本に間引き、本体の幅を 7.9 → 7.3 ユニット（半幅の拡大）、袖も 4.8 → 4.4 に広げた。コート系も本体を 8.2 → 7.9 に微拡大。マフラーの垂れは大きく描ける今日の人が担う。
- 日焼け止め（ボトル系4種）： 本体幅 6.8 → **8.2 ユニット**（BOTTLE／BOTTLE_SLASH）、BOTTLE_SUN は 6.4 → 7.2、BOTTLE_SHADE のボトルは 6.2×8.6 → 7.4×9.0 に拡大。チップ（30dp）と詳細の答え行（24dp）の両方で効く。
- 傘「開いた傘」「折りたたみ」はスクショの範囲では問題が読み取れなかったため無変更（線画1系統は維持）。

### 3. 人の立ち位置が右下に孤立

- 課題： 人がチップ列直上の右端に立ち、結論の特大文字と視覚的に切り離されて見えた。
- 直し方（MainActivity.showHome）： 人の行を **結論ブロックの直下**（上マージン 6dp、右端寄せ）へ移動し、空のスペーサーは人の下に移した。段階表示の順（結論→人→チップ→小行）は不変。背の高い画面では結論＋人が上部のひとかたまりになり、空はその下に広がる。最小画面ではスペーサーが潰れて従来に近い詰まり方になる。

## サイズと1画面収まりの再積算

- 人の高さ： 画面高 700dp 以上で 124 → **148dp**、620〜700dp で 104 → **128dp**、620dp 未満で **112dp**（`personHeightDp`）。
- 拡大の原資（余白の再配分）： ルート余白 上 24→20・下 16→12（−8）、結論の先頭文の上余白 12→10（−2）、gapNote の上余白 10→8（−2）、チップのラベル上余白 6→4（−2）、小行群の上余白 16→10（−6）と行間 6→5（5行時 −4）。人の上マージン +6 を差し引いても拡大分を賄える。
- 再積算（最小想定＝高さ620dp・フォント倍率1.0・最悪の文量、従来と同じ物差し）：
  ルート余白 32 ＋ 地点名 21 ＋ 結論（26sp・2文×2行＋上余白10）134 ＋ gapNote 34 ＋ **人 128＋上マージン 6** ＋ チップ列 116 ＋ 小行群（最大5行）140 ＝ **611dp ≦ 620dp** ✓
  標準想定（高さ700dp）： 余白 32 ＋ 地点名 21 ＋ 結論（30sp）154 ＋ gapNote 34 ＋ 人 148＋6 ＋ チップ 116 ＋ 小行 140 ＝ **651dp ≦ 700dp** ✓
  余りは従来どおりスペーサー（今は人の下）が吸収する。
